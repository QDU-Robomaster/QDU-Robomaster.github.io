# 算法组与电控组坐标系规范

本规范定义算法组与电控组之间传递姿态、角速度、加速度、速度、位置和目标位姿时使用的统一车体坐标系。所有跨模块、跨板、跨仓库的数据接口均以本规范为准。

## 1. 统一车体坐标系

车体坐标系统一采用标准自然系，即 `+X` 前、`+Y` 左、`+Z` 下：

| 轴向 | 正方向 |
| --- | --- |
| `+X` | 车体正方向，即车辆前进方向 |
| `+Y` | 车体左侧 |
| `+Z` | 车体下方 |

在三维笛卡尔坐标系下，我们把围绕y轴旋转的叫做Pitch(俯仰)，围绕x轴旋转的叫做Roll(横滚)，围绕z轴旋转的叫做Yaw(航向)，特别注意，在自然系下，pit抬头为负

## 2. BMI088 安装基准

本文中的 `bmi088` 坐标指电控驱动归一化后的 BMI088 / C 板坐标，而不是芯片寄存器直接读出的原始坐标。驱动侧应先把芯片原始轴转换为本文规定的自然系，再对外发布或参与后续安装矩阵计算。

以 C 板 USB 口方向作为板级 `+Y` 安装基准。标准安装状态下：

1. C 板 USB 口朝向车体 `+Y` 方向。
2. USB 口朝向定义为板级 `+Y`，与车体 `+Y` 一致。
3. C 板正面朝上时，垂直板面向下定义为板级 `+Z`，与车体 `+Z` 一致。
4. 板级 `+X` 指向车体正方向。

## 3. C 板到车体坐标系旋转矩阵

标准安装状态下，C 板 USB 口朝车体左侧，板级坐标轴与车体坐标轴逐一重合：

```text
bmi088 +X -> body +X
bmi088 +Y -> body +Y
bmi088 +Z -> body +Z
```

因此 BMI088 / C 板坐标系到车体坐标系的旋转矩阵为单位矩阵：

```text
R_body_bmi =
[ 1  0  0
  0  1  0
  0  0  1 ]
```

所有对外发布或发送给算法组的数据，应先完成坐标转换：

```text
acc_body   = R_body_bmi * acc_bmi
gyro_body  = R_body_bmi * gyro_bmi
att_body   = attitude calculated after applying R_body_bmi
```

这个矩阵按列来看：第 1 列表示 `bmi088 +X` 在车体坐标系中的方向，第 2 列表示 `bmi088 +Y` 在车体坐标系中的方向，第 3 列表示 `bmi088 +Z` 在车体坐标系中的方向。

标准安装时：

```text
bmi088 +X = body +X = [1, 0, 0]^T
bmi088 +Y = body +Y = [0, 1, 0]^T
bmi088 +Z = body +Z = [0, 0, 1]^T
```

把这三列依次放进矩阵，就得到单位矩阵。该矩阵只表示 C 板安装方向到车体坐标系的转换；BMI088 芯片原始轴到板级自然系的转换应在驱动内部先完成。
