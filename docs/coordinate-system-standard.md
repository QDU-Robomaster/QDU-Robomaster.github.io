# 算法组与电控组坐标系规范

本规范定义算法组与电控组之间传递姿态、角速度、加速度、速度、位置和目标位姿时使用的统一车体坐标系。所有跨模块、跨板、跨仓库的数据接口均以本规范为准。

## 1. 统一车体坐标系

车体坐标系采用右手系：

| 轴向 | 正方向 |
| --- | --- |
| `+Y` | 车体正方向，即车辆前进方向 |
| `+X` | 车体右侧 |
| `+Z` | 车体上方 |

角速度正方向遵循右手定则，分别记为 `omega_x`、`omega_y`、`omega_z`。算法组和电控组在接口中不得临时交换轴、取反轴或使用未说明的局部坐标系。

![BMI088 坐标系基准](/static/img/坐标系.png)

## 2. BMI088 安装基准

以 C 板上 BMI088 的正方向作为安装基准。标准安装状态下：

1. C 板 USB 口朝向车体正方向。
2. USB 口朝向定义为 `+Y`。
3. C 板正面朝上时，垂直板面向上定义为 `+Z`。
4. `+X` 由右手系确定。

在标准安装状态下，BMI088 坐标系与车体坐标系一致，BMI088 到车体坐标系的旋转矩阵为单位矩阵：

```text
R_body_bmi =
[ 1  0  0
  0  1  0
  0  0  1 ]
```

## 3. C 板旋转安装处理

如果 C 板相对车体发生旋转安装，电控侧必须同步调整 BMI088 到车体坐标系的旋转矩阵。所有对外发布或发送给算法组的数据，应先完成坐标转换：

```text
acc_body   = R_body_bmi * acc_bmi
gyro_body  = R_body_bmi * gyro_bmi
att_body   = attitude calculated after applying R_body_bmi
```

`R_body_bmi` 表示从 BMI088 坐标系转换到车体坐标系的旋转矩阵。该矩阵由实际安装方向决定，不能在算法侧用经验取反或交换轴的方式补偿安装误差。

常见仅绕 `+Z` 轴旋转的安装示例：

| C 板 USB 口实际朝向 | `R_body_bmi` |
| --- | --- |
| 车体前方 `+Y` | `[ [1, 0, 0], [0, 1, 0], [0, 0, 1] ]` |
| 车体右侧 `+X` | `[ [0, 1, 0], [-1, 0, 0], [0, 0, 1] ]` |
| 车体后方 `-Y` | `[ [-1, 0, 0], [0, -1, 0], [0, 0, 1] ]` |
| 车体左侧 `-X` | `[ [0, -1, 0], [1, 0, 0], [0, 0, 1] ]` |

如果安装包含翻面、俯仰或横滚旋转，应按实际三维安装姿态重新给出完整旋转矩阵，并在对应仓库配置或代码注释中说明。
